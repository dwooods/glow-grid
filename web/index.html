Barely lit means the pixel isn't black but ends up at 1–3 out of 255 on the LED, so it reads as off or a faint smudge. Use pure black for "off", or brighten it.

Tools

Ctrl+Z / Ctrl+Y. Erase sets a pixel to black, which is "off" on the panel.

LED settings

Keep brightness and gamma the same as BRIGHTNESS / GAMMA on the Pi (local_config.py). The sim uses the same rounding and "keep non-black pixels lit" rule. It's scaled so full white looks full on screen, so judge shapes and colors, not how bright it is.
